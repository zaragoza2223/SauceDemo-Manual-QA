# Как добавить документацию в GitHub

1. Откройте репозиторий `SauceDemo-Manual-QA`.
2. Нажмите **Add file → Upload files**.
3. Распакуйте архив и перетащите папку `Test-Cases` (содержимое папки `SauceDemo-Test-Cases-GitHub`) в репозиторий.
4. Нажмите **Commit changes**.

Файл `README.md` в корне этой папки станет оглавлением пяти разделов.
