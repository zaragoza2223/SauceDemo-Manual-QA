## 21. Cart-001 Добавление нескольких товаров в корзину

- **ID в Test IT:** 21
- **Приоритет:** Средний
- **Статус:** Готов
- **Оценка времени:** 0h 10m 0s
- **Ссылка в Test IT:** [Открыть кейс](https://team-lajl.testit.software/projects/3/tests/21)

### Предусловия

| Действие | Ожидаемый результат |
|---|---|
| авторизоваться под пользователем standard_user с паролем secret_sauce | авторизация проходит успешно, открывается страница products  с каталогом из 6 товаров |
| убедиться, что корзина пуста. При необходимости удалить ранее добавленные товары | корзина пуста, счётчик товаров отсутствует |

### Шаги

| Действие | Ожидаемый результат |
|---|---|
| нажать кнопку Add to cart на карточке любого товара | товар добавляется в корзину, кнопка меняется на remove, счётчик у иконки корзины отображает 1 |
| нажать кнопку Add to cart н карточке другого товара, отличного от добавленного на предыдущем шаге | второй товар добавляется в корзину, кнопка меняется  на remove,счётчик отображает 2 |
| нажать на иконку корзины | открывается страница корзины |
| проверить содержимое корзины | отображается оба добавленных товара с названиями и ценами, соответствующими выбранным карточкам каталога |
| проверить количество каждого товара | у каждого товара указано количество 1 |
