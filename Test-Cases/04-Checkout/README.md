## 25. Checkout - 001 Успешное оформление заказа

- **ID в Test IT:** 25
- **Приоритет:** Средний
- **Статус:** Готов
- **Оценка времени:** 0h 10m 0s
- **Ссылка в Test IT:** [Открыть кейс](https://team-lajl.testit.software/projects/3/tests/25)

### Предусловия

| Действие | Ожидаемый результат |
|---|---|
| Авторизоваться под пользователем standard_user с паролем secret_sauce | Авторизация проходит успешно. Открывается страница Products, с каталогом из 6 товаров |
| Добавить в корзину два разных товара | Оба товара добавлены, счётчик у иконки корзины отображает 2 |
| Открыть корзину | Отображаются 2 добавленных товара с корректными названиями и ценами |

### Шаги

| Действие | Ожидаемый результат |
|---|---|
| Нажать кнопку Checkout | Открывается страница оформления заказа |
| Ввести имя Alex в поле First Name | Имя введено и отображается в поле |
| Ввести фамилию Tester в поле Last Name | Фамилия введена и отображается в поле |
| Ввести индекс 12345 в поле Zip/Postal Code | Индекс введён и отображается в поле |
| Нажать кнопку Continue | Открывается страница Checkout: Overview |
| Проверить информацию о товарах | Отображается добавленный товар с корректными названием, ценой и количеством 2 у иконки корзины |
| Проверить итоговую стоимость заказа | Отображается стоимость товаров, налог и итоговая сумма. Итоговая сумма соответствует сумме стоимости товаров и налога |
| Нажать кнопку Finish | Заказ успешно оформляется, открывается страница Checkout:Complete! |
| Проверить сообщение о завершение заказа | Отображается сообщение Thank you for your order! |
