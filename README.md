SauceDemo — Manual QA Testing

Учебный pet-проект по ручному тестированию веб-приложения SauceDemo.

О проекте

Цель проекта — получить практический опыт ручного тестирования веб-приложения, научиться составлять тестовую документацию, выполнять тест-кейсы и оформлять баг-репорты.

Области тестирования

Login — авторизация, проверка корректности введённых данных.

Inventory — каталог товаров, сортировка, добавление товаров в корзину.

Cart — добавление нескольких товаров, удаление товаров, очистка корзины.

Checkout — оформление заказа, проверка обязательных полей, отмена оформления, генерация PDF.

Session and UI — боковое меню, навигация, выход из аккаунта, сброс состояния приложения, Dynamic Catalog.

Виды тестирования

Функциональное тестирование.

Позитивное и негативное тестирование.
